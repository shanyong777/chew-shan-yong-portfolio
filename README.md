# Chew Shan Yong — Personal Portfolio Website

A fast, responsive, modern glassmorphic personal profile website for **Chew Shan Yong** (Bachelor of Information Systems Honours, UTAR).

## Project Structure
```
├── index.html        # Main HTML file
├── style.css         # Custom styling, glassmorphism, animations & print resume styling
├── app.js            # Canvas particles, multi-language engine (EN/ZH/BM), theme switcher, sound synthesis
└── assets/           # Profile images, icons, and PDF resume
    ├── profile.jpg
    ├── avatar_pixel.png
    ├── Chew_Shan_Yong_Resume.pdf
    └── projects/
```

## How to Make It Live (Free & Instant Deployment Options)

### Option 1: Vercel (Recommended — 30 Seconds)
1. Go to [vercel.com](https://vercel.com) and sign in.
2. Drag and drop this `chew-shan-yong-portfolio` folder into Vercel or connect via GitHub.
3. Your live link will be generated instantly (e.g. `https://chewshanyong.vercel.app`).

### Option 2: Netlify (Instant Drag & Drop)
1. Go to [app.netlify.com/drop](https://app.netlify.com/drop).
2. Drag and drop the `chew-shan-yong-portfolio` folder onto the page.
3. Your site is live immediately!

### Option 3: GitHub Pages
1. Create a new GitHub repository named `chewshanyong.github.io` (or any name).
2. In this folder:
   ```bash
   git init
   git add .
   git commit -m "Deploy portfolio"
   git branch -M main
   git remote add origin https://github.com/<YOUR-USERNAME>/<REPO-NAME>.git
   git push -u origin main
   ```
3. In GitHub repo settings -> **Pages** -> Select `main` branch -> Save.
